# Mirage Host

This repository holds no code. It hosts the notarized downloads of Mirage Host, the free Mac app that lets Mirage on an
iPhone, iPad or another Mac control a Mac through Remote Control.

Get it, and read what it needs, at https://www.getmirage.dev/host.

Each [release](https://github.com/heydaytime/mirage-host/releases) is one Mirage Host version: `MirageHost.dmg`, signed
with Developer ID and notarized by Apple, with its SHA-256 in the release notes. The newest is always at
https://github.com/heydaytime/mirage-host/releases/latest/download/MirageHost.dmg.
